# WignerSolver ver. 0.241228

Program for solving Boltzmann-Poisson and Wigner-Poisson set of equations.

* Written in C++ and based on armadillo library. Due to use of spare matrices SuperLU library is needed.
* Classes are located in 'src' folder
* Program is compiled through makefile
* To disable multi-threading, please delete '-fopenmp' in makefile.
